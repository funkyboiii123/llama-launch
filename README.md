# *llama-launch*
Run [llama.cpp](https://github.com/ggml-org/llama.cpp/releases/latest) releases (or other forks like [beellama.cpp](https://github.com/Anbeeld/beellama.cpp/releases/latest)) with a few simple files.

## Instructions:

* Clone the repo: ` git clone https://github.com/funkyboiii123/llama-launch `
* [Install Git-Bash](https://git-scm.com/install/) to open .SH (shell-script) files if you don't already have Bash.
